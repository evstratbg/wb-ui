# Wiren Board — полный UI concept

Альтернативный полный фронтенд установленной версии Wiren Board: `v2.208.1-wb100`, upstream commit `0546d10e7ade2894baa5a828549900b708ca52a8`. Это fork настоящего приложения с сохранёнными страницами, редакторами, транспортом MQTT/RPC, авторизацией и правами. Интерфейс не встраивает прежний UI и не отправляет пользователя на порт 80 для настройки.

После установки интерфейс доступен на `http://<controller>:8080/#!/overview`. Используйте адрес своего контроллера и существующую учётную запись. Сессия разделяется между портами одного hostname; обычный выход завершает общую браузерную сессию WB.

## Что изменено

- Новая постоянная навигация, контекстная строка, зелёная палитра WB, более ясная типографика, отступы, таблицы, формы и диалоги во всех штатных разделах.
- Новый обзор с реальными температурой, питанием, временем работы, состоянием каналов, сетью и историей CPU/платы.
- Избранные каналы на основе штатного компонента Cell, настраиваемые локально в браузере.
- Поиск по именам устройств, MQTT ID и каналам, доступный из навигации и раздела устройств.
- Редакторы обычных панелей и виджетов, SVG и привязок, правил и конфигурации работают внутри приложения на том же порту.
- Сохранены serial/Modbus, сеть, пользователи и роли, история, журналы, системное обслуживание, MQTT-каналы, DALI и установленные интеграции/динамическое меню.
- Настройка панели по умолчанию продолжает работать при открытии корня; новый обзор доступен отдельно в меню и по `/#!/overview`.
- Обзор и новые элементы поддерживают RU/EN. Сохранены переменные и существующие средства разработки тем.
- Исправлена совместимость старой SVG-панели без поля `swipe`: значения по умолчанию добавляются в памяти редактора. Неверный SVG-атрибут `width="auto"` нормализуется только при отображении. Исходная конфигурация и привязки не переписываются.

Подробное покрытие штатных функций: [deploy/CAPABILITIES.md](deploy/CAPABILITIES.md).

## Сборка

```sh
cd frontend
cp .env.concept .env
npm ci
npm test -- --runInBand
npm run build
```

Сборка — `frontend/dist/`. На контроллере работают только статические файлы и nginx, Node.js/npm ему не нужны. Зафиксированная версия зависимостей находится в package-lock.json.

`DISABLE_HTTPS_CHECK=true` отключает автоматический переход этого дополнительного фронтенда с 8080 на штатный HTTPS-порт 443. Общие настройки HTTPS контроллера и его штатный интерфейс не изменяются.

## Установка и отключение

Смотрите [deploy/README.md](deploy/README.md). Статика размещается на разделе данных `/mnt/data/wb-ui/releases`, активная версия выбирается ссылкой `current`. Добавляется только сервер nginx для 8080, штатный UI остаётся на 80. Предыдущий release сохраняется; установщик откатывает файлы при ошибке проверки или reload nginx.

Backend и его auth/ACL переиспользуются через reverse proxy. Это позволяет не менять службы, прошивку и рабочие конфигурации WB. Поддержаны native uploads, резервные копии, диагностические файлы и SVG assets.

## Проверка

- `npm test -- --runInBand`: **78/78 тестов**, включая 23 новые регрессионную проверку маршрутов, ролей, обзора, локализации и legacy SVG.
- Production Webpack build проходит. Два предупреждения о размере bundles соответствуют сохранённому полному приложению.
- `tsc --noEmit`: 31 ошибка в исходном upstream и те же 31 после изменений; новых ошибок нет. Эти существующие ошибки не исправлялись в рамках UI.
- Браузер: вход/session, live MQTT, поиск, реальные графики, обычные/SVG панели и редактор, диалог редактирования виджета, существующий rule editor, реальные записи журнала, устройства и порты, пользователи, сеть, MQTT, configs, widgets и Alice.
- Проверены desktop 1440 px, mobile 390 px и ширина панели 544 px. Примеры — [публичные снимки](docs/images/).
- Физические выходы не переключались; операционные конфигурации, пользователи, сеть и firmware не сохранялись/обновлялись. Автопоиск шин не запускался. Наличие редактора не является доказательством выполнения реального обновления прошивки или смены сети. DALI сохранён в исходниках; работа реального DALI-оборудования не проверялась.

## Основные файлы

- `frontend/src/components/navigation/` — оболочка приложения.
- `frontend/app/styles/concept.css` — общие native компоненты и адаптация.
- `frontend/src/pages/overview/` — новый обзор и реальная история.
- `frontend/src/pages/devices/` — поиск устройств и каналов.
- `frontend/src/stores/ui/menu-items.ts` — навигация и права.
- `frontend/src/pages/dashboards/svg/` и `frontend/src/utils/svg-for-display.ts` — совместимость SVG.
- `frontend/test/react/concept/` — регрессионные тесты.
- `deploy/` — установка, reverse proxy и откат.

Это независимое предложение интерфейса, не официальный релиз Wiren Board. Исходная MIT-лицензия и авторство сохранены в [LICENSE](LICENSE). Backend и пакетные конфигурации оставлены исходными; deploy использует существующий backend установки.
