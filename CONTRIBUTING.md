# Участие в wb-ui

Это независимый экспериментальный проект на основе Wiren Board homeui. Обсуждения и изменения для него ведутся в [Issues](https://github.com/evstratbg/wb-ui/issues) и pull requests этого репозитория.

## Предложение улучшения

Опишите конкретную задачу: кто её выполняет, как выглядит текущий путь, что мешает и какой результат станет проще. Для новых сценариев полезен короткий пример «до / после». Текущие идеи собраны в [ROADMAP.md](ROADMAP.md).

## Изменения кода

1. Создайте ветку от `main` и ограничьте PR одной задачей.
2. Сохраните backend-совместимость и проверки ролей. Учитывайте, что UI управляет реальным оборудованием.
3. Выполните в `frontend/`: `npm ci`, `cp .env.concept .env`, `npm test -- --runInBand`, `npm run build`.
4. Для UI приложите desktop/mobile-снимки с демонстрационными данными и опишите проверенный сценарий.
5. Укажите ограничения проверки. Открытие редактора и успешная сборка не доказывают выполнение операции на оборудовании.

Не добавляйте пароли, токены, дампы и персональные конфигурации контроллера. Регрессионные проверки операций пишите на фикстурах; предпросмотры и тестовая навигация не должны переключать реальные выходы.

Известное ограничение: `tsc --noEmit` содержит 31 ошибку базового upstream. Сравнивайте новые диагностики с исходной версией; тесты и production build проверяются отдельно.
