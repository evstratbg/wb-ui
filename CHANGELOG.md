# Changelog

## v0.2.0 - 2026-10-23

Два переключаемых рабочих режима и реализация всех четырёх пунктов предыдущего ROADMAP. Экспериментальный prerelease на базе homeui v2.208.1-wb100; совместимость проверена с соответствующим backend WB7.

## Что нового

- **«Мой дом»:** избранные каналы с существующих панелей, свои подписи и порядок, вход в обычные и SVG-панели, история и смена языка. Первое избранное отдаёт приоритет управлению и измерениям. Настройки подборки и режима локальны для браузера.
- **«Настройка»:** полная техническая навигация и единая карточка устройства. Обычный пользователь получает домашний режим; оператор и администратор могут переключаться. Режим не меняет права учётной записи.
- **Опрос рядом с каналом:** параметры из точного сопоставления с шаблоном, штатные ограничения режима/периода, проверка полного состава изменений до записи общей конфигурации `wb-mqtt-serial`.
- **Сравнение истории:** единый поиск нескольких каналов, немедленная загрузка, периоды 1ч/6ч/24ч/7д с выделением выбранного и постоянно видимым диапазоном/часовым поясом, свои даты, разные единицы на отдельных шкалах, воспроизводимые URL, отмена загрузки, свёрнутая таблица и CSV из всех полученных точек.
- **Редактор текстовых панелей:** каналы → расположение → предпросмотр → изменения; черновик в памяти, явное сохранение/отмена. Общий виджет по умолчанию копируется для текущей панели; изменение на всех панелях выбирается явно. Предпросмотр не содержит команд оборудованию.
- **Диагностика правил:** ошибка backend, строка и фрагмент сохранённого кода, стек ошибки, живые сообщения WB Rules и явная загрузка до 20 записей журнала рядом с редактором. Debug автоматически не включается.

## Исправления

- Изменение режима не теряет черновик при отменённом переходе.
- Потеря связи блокирует команды на домашнем экране и текстовых панелях, включая элементы в порталах.
- Ошибка или конфликт сохранения панели оставляет черновик; глобальные панели обновляются после успешной записи.
- Запоздавшие ответы отменённой истории не подменяют новый результат. Нулевые границы и точные ID каналов со слешами сохраняются.
- CSV не зависит от раскрытия таблицы; текстовые формулы экранируются, числовые нули и отрицательные значения сохраняются.
- Ошибки правил сохраняют traceback и отдельный снимок исходника: загруженного или отправленного. Редактирование C не подменяет фрагмент ошибочного B; переход по строке разрешён только при совпадении текста. Ошибка Save не объявляется успешной записью. Неудачное переименование остаётся доступным для повторного сохранения.
- Язык в «Моём доме» меняется без записи настроек панели на контроллер.

## Установка

Готовая сборка **wb-ui-static.tar.gz** и **SHA256SUMS** приложены к релизу. Node.js/npm/Git на WB не нужны. Сначала проверьте SHA-256, затем следуйте [инструкции установки](https://github.com/evstratbg/wb-ui/blob/v0.2.0/README.md#установка). Дополнительный UI работает на 8080; штатный порт 80 остаётся доступным. Для обновления используйте тот же установщик; откат описан в `deploy/README.md`.

## Границы версии

- Режим — представление интерфейса, не отдельная система разрешений. Авторизация и роли остаются штатными.
- Черновики панелей/настроек находятся в памяти и не переживают обновление страницы. Сохранение пишет соответствующую конфигурацию целиком. Предварительная проверка устаревших данных не является атомарным compare-and-swap backend.
- Новый пошаговый редактор предназначен для текстовых панелей; SVG использует штатный редактор. Совместимость с другими версиями backend отдельно не подтверждена.
- CSV содержит полученные точки, включая агрегацию backend. Сообщения без имени файла нельзя надёжно отнести к конкретному правилу. Retained MQTT не доказывает физическую связь с модулем.
- Локальные проверки и объём live QA зафиксированы в README. CI этого тега выполняет тесты и production build до публикации архива. `tsc --noEmit` сохраняет 31 исходную ошибку upstream.

## Проверка

Локально: **141/141 тест в 11 suites**, production build с двумя исходными предупреждениями о размере bundles; 31 ошибка TypeScript совпадает с upstream. На WB7 проверены оба режима, RU/EN, параметры опроса, сравнение реальной истории, скачивание CSV, черновик/отмена/безопасный предпросмотр панели, живые сообщения и 20 записей журнала правил на 1440/544/390 px. Сохранение и отказы записи проверены изолированными тестами. Во время live QA рабочая конфигурация не записывалась, физические выходы не переключались; контрольные суммы serial/Web UI config совпали.

## v0.1.0 — 2026-10-21

### Добавлено

- Новая навигация и общие стили штатных страниц.
- Обзор с живыми показаниями, историей и локальным избранным.
- Поиск устройств и каналов; адаптация к мобильному экрану.
- Рабочее место устройства: вкладки каналов, настроек, истории и диагностики; точное сопоставление с конфигурацией `wb-mqtt-serial` по MQTT ID.
- Каталог с поиском по порту/адресу и фильтрами; для администратора — устройства из конфигурации до получения MQTT-каналов и явные конфликты повторяющихся ID.
- Группы управления, входов, измерений и свёрнутых служебных каналов; история выбранного канала без выхода из карточки.
- Диагностика ошибок устройства/каналов, полученных версий firmware/bootloader и журнал драйвера по запросу.
- URL с поиском, фильтром, устройством, вкладкой и каналом истории; сохранение черновика при внутренних переходах.
- Явная запись всей конфигурации `wb-mqtt-serial` с проверкой изменений в другом окне перед сохранением; подтверждение чтения регистров и отмены всего черновика.
- Установка на дополнительном порту 8080, отключение и восстановление предыдущей сборки.
- Готовая сборка в GitHub Releases с SHA-256: установка на WB без Node.js, npm и клонирования репозитория. Публикация архива после успешного CI по тегу версии.
- Регрессионные проверки, публичная документация и CI-сборка.

### Исправлено

- Загрузка старой SVG-конфигурации без `swipe`.
- Отображение SVG с `width="auto"` без изменения исходной панели.
- Читаемость осей графика на узких экранах.
- Расположение строк перевода поиска в namespace устройств.
- Сохранение MQTT-ошибки устройства в модели и её отображение в статусе/диагностике.
- Коррекция диапазона истории устройства при различии часов браузера и контроллера.
- Блокировка редактирования настроек во время сохранения и потери связи, включая уже раскрытые выпадающие списки.

### Основа и границы

homeui `v2.208.1-wb100`, `0546d10e7ade2894baa5a828549900b708ca52a8`. Сохранены штатные backend, транспорт, права и редакторы. Настройки/конфигурация портов и сведения о прошивке требуют администратора. Новый экран не обновляет firmware; полные операции остаются в штатном редакторе портов. Проверка перед сохранением не является атомарной блокировкой backend. Автосохранения черновика нет.

Локально пройдены 114/114 тестов в 9 suites и production build; `tsc --noEmit` воспроизводит ровно 31 исходную ошибку upstream. Новая сборка установлена на WB7 на порту 8080: четыре вкладки, реальные история/журнал, поиск, переходы и черновик проверены на desktop/mobile без сохранения рабочей конфигурации или операций с оборудованием. Результаты проверок опубликованных ревизий — в [GitHub Actions](https://github.com/evstratbg/wb-ui/actions/workflows/ci.yml). Сравнение нескольких каналов в новом сценарии, переработка редактора панелей и диагностика правил остаются в [ROADMAP](ROADMAP.md).
