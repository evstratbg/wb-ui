## Совместимость

| Компонент | Условия |
| --- | --- |
| Основа | homeui `v2.208.1-wb100`, коммит [`0546d10`](https://github.com/wirenboard/homeui/commit/0546d10e7ade2894baa5a828549900b708ca52a8) |
| Проверено | WB7 с backend этой версии; совместимость с другими версиями отдельно не подтверждена |
| Сборка | Node.js 22, npm; версия Node указана в [.nvmrc](../.nvmrc) |
| На контроллере | Статические файлы, nginx и штатные службы WB; Node.js не нужен |
| Размещение | Дополнительный HTTP-порт `8080`, штатный интерфейс остаётся на `80` |

Приложение сохраняет существующий стек AngularJS + React 18 и Webpack. Это позволяет использовать штатные редакторы и установленные API без замены backend.

## Разработка и проверки

```sh
cd frontend
npm ci
cp .env.concept .env
npm test -- --runInBand
npm run build
```

Для разработки настройте `MQTT_BROKER_URI` и адрес backend в webpack-конфиге под свой контроллер, затем запустите `npm start`. Dev-сервер использует реальные службы контроллера; это не изолированный симулятор. Подробности исходного проекта — в [upstream README](UPSTREAM.md).

Workflow CI выполняет тесты, production build и проверку синтаксиса deploy-скриптов. Для тегов `v*` после успешных проверок публикуются архив сборки и `SHA256SUMS` в GitHub Releases. Архив содержит установщик, nginx-конфиг, сведения о ревизии и лицензии. Публичные файлы релиза предназначены для установки; промежуточный Actions-артефакт `wb-ui-static` хранится 14 дней. Автоматической установки на контроллер нет. Результаты проверок каждой опубликованной ревизии доступны в [GitHub Actions](https://github.com/evstratbg/wb-ui/actions/workflows/ci.yml).

## Проверка v0.2.0

Ниже — зафиксированный объём проверки v0.2.0. Статус последующих изменений смотрите в GitHub Actions.

Локально пройдены **141/141 тест в 11 suites** и production build с двумя исходными предупреждениями о размере bundles. У `tsc --noEmit` остаются ровно те же 31 ошибка upstream. Новая сборка установлена на WB7 на порту 8080: проверены переключение режимов, локальная смена языка, опрос канала и полный diff, сравнение температуры/напряжения и скачивание CSV, черновик/отмена/предпросмотр панели, живые сообщения и 20 записей журнала правил. Ширины проверки — 1440, 544 и 390 px. Успешные и неуспешные записи, конфликты конфигурации, отмена загрузки и offline-блокировки проверяются изолированными тестами. Контрольные суммы рабочей конфигурации serial/Web UI до и после live QA совпали; физические выходы, firmware, сеть и пользователи не изменялись. [Подробный объём проверки](../README-UI-CONCEPT.md#проверка).
