# Реализованные сценарии

Все четыре пункта предыдущего плана реализованы в **v0.2.0**. Добавлены два переключаемых режима: «Настройка» для инсталлятора и «Мой дом» для владельца. Следующие задачи и сроки пока не заявлены; предложения можно обсуждать в Issues.

## Для инсталлятора

- **Единая карточка устройства:** каналы, настройки, история и диагностика. Точная связь с `wb-mqtt-serial` по MQTT ID, порт и адрес без повторного поиска. Конфликт ID и отсутствие конфигурации показаны явно; администратор видит настроенные модули ещё до получения каналов.
- **Настройки опроса из строки канала:** загружается штатный шаблон, применяется точное сопоставление MQTT ID/имени канала в шаблоне, сохраняются условия, поддержка firmware и ограничения периода. Если соответствие неоднозначно, предлагается полный редактор. Перед сохранением показывается полный diff; записывается вся конфигурация serial backend, включая общий черновик других устройств.
- **Сравнение истории:** один поиск каналов, немедленная загрузка, периоды 1ч/6ч/24ч/7д, свои даты, независимые шкалы разных единиц/типов, ссылки с каналами и датами, отмена устаревших запросов, свёрнутая таблица и CSV из данных.
- **Редактор текстовых панелей:** каналы → расположение → предпросмотр → изменения. Черновик в памяти, явное сохранение/отмена и проверка конфигурации перед записью. Общий виджет по умолчанию копируется для текущей панели; изменение на всех панелях выбирается явно. Предпросмотр содержит показания без команд управления. SVG использует штатный редактор.
- **Диагностика правил рядом с кодом:** ошибка backend, traceback, строка и фрагмент исходника ошибки, живые сообщения WB Rules, выбор файла/общего потока и явная загрузка до 20 записей журнала. Переход по строке разрешён только при совпадении текста редактора с диагностическим снимком. Автоматического включения debug нет.

Оператору доступны каналы, история, диагностика и текстовые панели. Настройки serial, конфигурация портов, firmware и правила требуют администратора. Полное дерево портов и штатные системные инструменты сохранены.

## Для владельца

«Мой дом» показывает элементы существующих панелей и вход в обычные/SVG-панели. Избранные каналы можно выбрать, подписать и упорядочить в этом браузере. Начальная подборка отдаёт приоритет управлению и измерениям. Есть история и смена языка без технических настроек подключения. При потере связи управление блокируется; значения не обозначаются как свежие.

Обычный пользователь открывает домашний режим. Оператор и администратор могут переключаться кнопкой в верхней строке или мобильном меню. Режим не меняет авторизацию и не заменяет штатные роли WB.

## Проверка и ограничения

Новые сценарии проверены на WB7 с соответствующим backend на ширинах 1440, 544 и 390 px: реальные данные истории, CSV, журнал правил, параметры опроса, локальные черновики и их отмена. Сохранение рабочей конфигурации и управление физическими выходами на контроллере не выполнялись; успешные/неуспешные записи, конфликты, роли, отмена запросов и блокировка offline проверяются изолированными тестами. [Объём проверки](README-UI-CONCEPT.md#проверка).

Черновик не переживает обновление страницы. Сохранение пишет соответствующую конфигурацию целиком; проверка актуальности не является атомарной блокировкой backend. CSV содержит полученные точки, в том числе агрегацию backend. Сообщение без имени файла нельзя надёжно отнести к правилу. Retained MQTT и отсутствие ошибки не доказывают физическую связь с модулем.
